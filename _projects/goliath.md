GOLIATH reconstructs private tabular training data from shared gradients or model updates by jointly optimizing the data and diffusion latents. It supports Gaussian and masked diffusion models.

The repository contains the implementation and experiment scripts for **GOLIATH: Gradient Inversion of Tabular Diffusion Models**, published at NeurIPS 2026.
